## 🧪 Troubleshooting Cases

This repository focuses on real-world Linux issues and incident-style debugging.

Each case is based on a broken system scenario and follows a structured approach:

- problem / symptoms  
- investigation process (commands + reasoning)  
- root cause  
- solution  
- prevention  

### What to expect

- minimal setup, maximum troubleshooting  
- realistic failure scenarios (misconfiguration, access loss, service issues)  
- step-by-step analysis instead of tutorials  
- focus on understanding *why things break* and how to fix them  

### Example cases

- SSH access lost (misconfigured authentication)  
- Disk full causing system issues  
- Permission denied (file ownership / access problems)  
- Service not starting (systemd / logs analysis)
